> Небольшое, но наглядное приложение на **Node.js**, созданное для
> демонстрации базовой структуры веб-проекта.\
> Цель разработки --- показать, как организуется окружение,
> устанавливаются зависимости и запускается простой сервер.

## ⚙️ Среда выполнения

  -----------------------------------------------------------------------
  Компонент         Требуемая версия                Примечание
  ----------------- ------------------------------- ---------------------
  **Node.js**       ≥ 17.0.0                        Рекомендуется LTS

  **npm**           ≥ 9.0.0                         Устанавливается
                                                    вместе с Node.js

  **ОС**            Linux / Windows / macOS         Подходит любая
                                                    современная система
  -----------------------------------------------------------------------

------------------------------------------------------------------------

## 🚀 Как запустить проект

``` bash
# Установка зависимостей проекта
npm install

# Запуск локального сервера
npm start
```

------------------------------------------------------------------------

## 🧪 Проверка работоспособности

-   Убедитесь, что сервер запущен без ошибок.
-   Откройте браузер и перейдите по адресу, указанному в терминале.
-   Проверьте, выводится ли приветственное сообщение.
-   При необходимости измените порт в конфигурации\
    (см. репозиторий проекта).
