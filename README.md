 Небольшое, но наглядное приложение на **Node.js**, созданное для
 демонстрации базовой структуры веб-проекта.\
 Цель разработки --- показать, как организуется окружение,
 устанавливаются зависимости и запускается простой сервер.

## ⚙️ Среда выполнения

|Компонент|Версия|Комментарий|
|---|---|---|
|Node.js|>17.0.0|Рекомендуется LTS-версия|
|npm|>9.0.0|Устанавливается вместе с Node.js|
|ОС|Linux/ Windows/ macOS|Любая современная ОС|

------------------------------------------------------------------------

## 🚀 Как запустить проект

``` bash
# Установка зависимостей проекта
npm install

# Запуск локального сервера
npm start
```

------------------------------------------------------------------------

## 🧪 Проверка работоспособности

-   Убедитесь, что сервер запущен без ошибок.
-   Откройте браузер и перейдите по адресу, указанному в терминале.
-   Убедитесь, выводится ли приветственное сообщение.
-   При необходимости измените порт [конфигурации](https://github.com/arslan-barslan/practica1/edit/master/README.md)
